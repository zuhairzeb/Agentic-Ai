## How to use these files
1. Add all files to the agent's knowledge or retrieval system.
2. Keep each topic in its own file. This makes retrieval more reliable than one very large file.
3. Treat facts marked **Needs confirmation**, **historical**, or **uncertain** as lower confidence.
4. Never turn a goal, draft, or proposal into a claim that it has already happened.
5. For current facts such as event dates, member counts, roles, links, job openings, or policies, ask for an update or verify them before acting.
6. Do not expose private contact details, personal history, or internal society information in public content unless the user asks.
