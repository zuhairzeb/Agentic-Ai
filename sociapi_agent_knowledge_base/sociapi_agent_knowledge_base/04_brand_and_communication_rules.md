# Sociapi Society Brand and Communication Rules

## Brand colors
Use only these brand colors in Sociapi designs:
- Dark Green: `#517642`
- Light Green: `#7BD355`
- Light Gray: `#E8ECEE`
- Gray: `#939596`
- Dark Gray: `#333333`

Do not add extra colors. The user specifically does not want pure black or pure white in Sociapi designs.

## Fonts
- Tomorrow
- Neue Machina

Use these fonts only in brand designs when available.

## Logo
- Use the supplied official logo without changing it.
- Logo includes a circuit brain, “SOCIAPI SOCIETY”, and the tagline.
- Do not redraw, distort, recolor, or modify the logo.
- Use one logo in the header where the layout calls for it.
- Add `@sociapi` in the footer when requested by the design brief.

## Visual style
Preferred style:
- Premium editorial layout
- Swiss-grid structure
- Clear spacing and alignment
- Canva-editable layouts
- Social post format often 4:5, 1080 × 1350
- Strong typography and clean information hierarchy

Avoid:
- AI-looking visuals
- Neon effects
- Glassmorphism
- Floating decorative icons
- Cheap or random icons
- Unnecessary gradients
- Extra logos
- Decorative elements that reduce clarity

## Service card labels previously used
- WP Dev
- Web Dev
- UI/UX
- Video Editing
- Graphic Design
- POS SOFTWARE
- Content Writing

## Writing style
- Use simple, clear English or Roman Urdu.
- Do not use Hindi script.
- Avoid difficult words and generic AI-sounding language.
- WhatsApp messages should be concise and natural.
- LinkedIn copy should not include emojis.
- For society recruitment, use an inviting but direct student-community tone.
- Do not invent details to make copy sound more impressive.
- Use dates, names, numbers, and claims only when supported.

## Example short society description
“Sociapi Society is a student-led technology community at Islamia College University Peshawar. We bring students together to learn, build projects, share ideas, and explore AI, programming, robotics, and web development. Our tagline is ‘From Ideas to Intelligence.’”
