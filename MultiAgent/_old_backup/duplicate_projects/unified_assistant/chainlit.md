# Unified Multi Agent AI Assistant

Ask a question and the assistant will choose the right specialist. You can also select one directly with a command:

- `math Calculate 15% of 200`
- `writer Draft a professional email`
- `agent1 Explain Python decorators`
- `agent2 Explain Python decorators in detail`

Gemini powers math and writing. Groq powers general questions and the two selectable conversation agents. Chat history is kept only for the current session.
